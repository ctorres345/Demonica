# Notes for AI assistants

Demonica is a Flutter companion app for Shin Megami Tensei IV fusions. Start with CONTRIBUTING.md; it links every other doc.

- Code reaches `main` only through a pull request. Work on a branch named `cesar/DEM-n`.
- Doc-only changes (Markdown files and nothing else) go straight to `main`, with no branch or PR.
- Open the PR with `.github/pull_request_template.md`. UI changes need before/after screenshots, light and dark.
- Cesar merges every PR. Never merge one yourself.
- There is no CI. Run `tool/check.sh` and make sure it passes before every push.
- Engine logic goes in `packages/fusion_core` (pure Dart, no Flutter). UI reads state only through providers. See docs/ARCHITECTURE.md.
- Colors, spacing and type come from `lib/design_system/tokens.dart` via `context.dc`, `context.ec`, `context.tt`. Default palette is Strange Journey. See docs/DESIGN_SYSTEM.md.
- `assets/data/smt4/` is generated by `tool/import_smt4.dart`; never edit it by hand.
- The app is never tied to the player's save: no level, party or owned-demon tracking.
- Commit messages start with the Jira key: `DEM-n: summary`.
- Write user-facing text and docs in short, plain sentences. Tables and diagrams over long paragraphs.
